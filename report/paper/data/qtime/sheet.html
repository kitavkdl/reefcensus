이 물체를 물고기 수에 넣을까요?

무엇을 재나

우리 프로그램은 확신이 없는 물체를 바로 세지 않고 사람 확인 대기열에 보냅니다. 이 페이지는 그 확인에 사람이 몇 분 쓰는지 잽니다. 결과는 "기계 + 사람 확인 몇 분"이라는 숫자로 영상·제출 폼에 들어갑니다. 빨리 할 필요는 없고, 평소 판단하시는 속도면 됩니다.

할 일

  1. 아래 시작을 누르면 시간이 잽니다.
  2. 카드 9장마다 버튼 하나씩 누릅니다.
  3. 다 끝나면 맨 아래 답 복사를 누르고 채팅에 붙여 넣어 주세요(이때 시간이 멈춥니다).

카드 보는 법

  • 카드 한 장 = 컴퓨터가 영상에서 따라간 물체 하나. 사진(최대 3장, 옆으로 넘기기)은 같은 물체의 처음·중간·끝입니다.
  • 노란 상자 = 컴퓨터가 "물고기"로 찾은 것.
  • 컴퓨터 메모 = 컴퓨터(Muse Spark)가 이 물체를 보고 남긴 한 줄(영어). 이 메모 때문에 대기열에 왔습니다. 참고만 하시고 판단은 사진으로 해 주세요.

선택지 — 무엇을 누르면 어떻게 되나

넣기
노란 상자 안이 물고기다(희미해도 물고기로 보이면 넣기). → 이 물체가 물고기 수(MaxN)에 들어갑니다.
빼기
물고기가 아니다(물·해초·그림자·화면 글자 등). → 물고기 수에서 빠집니다.
모르겠음
사진만으로 판단이 안 된다. → 물고기 수에서 빠진 채로 "다시 볼 것"으로 남습니다. 억지로 고르지 않으셔도 됩니다.
